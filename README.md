# 📱 Smart Spam Message Detector

A machine learning-based web application that detects whether a message is **Spam** or **Not Spam**.

## 🎯 Objective

The objective of this project is to identify unwanted or spam messages using machine learning and provide a simple web interface for users.

## 🚀 Features

- Enter any SMS or message
- Classifies the message as Spam or Not Spam
- Simple and user-friendly interface
- Machine learning-based prediction
- Online web application using Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Machine Learning
- GitHub

## 📂 Project Files

| File | Description |
|---|---|
| `app.py` | Main Streamlit application |
| `spam_model.pkl` | Trained machine learning model |
| `train_model.py` | Model training program |
| `requirements.txt` | Required Python libraries |

## ⚙️ How It Works

1. User enters a message.
2. The application processes the message.
3. The trained machine learning model analyzes it.
4. The application predicts whether the message is **Spam** or **Not Spam**.
5. The result is displayed to the user.

## 🌐 Live Demo

The application is deployed using Streamlit Community Cloud.
